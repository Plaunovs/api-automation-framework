## API Test Automation Framework

Automatizētu REST API testu projekts, izveidots ar **Mocha** un **Mochawesome**, lai testētu API galapunktus (piemēram, lietotāja reģistrāciju un datu ievadi).

##  Funkcionalitāte
- Strukturēti testi: scenarios → steps → utils
- Datu ievade no JSON failiem
- HTTP pieprasījumi ar Axios/fetch
- Automātiski ģenerētas HTML atskaites ar Mochawesome

##  Tehnoloģijas
- Node.js  
- Mocha  
- Mochawesome  
- JavaScript (ES6)  
- REST API

npm install
